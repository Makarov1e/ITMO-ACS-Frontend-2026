## Быстрый запуск итогового приложения

Проверенная среда: Node.js 22.13.0, npm 10.9.2, Linux. Из корня репозитория:

```bash
cd "labs/К3440/Макаров Егор/lab3"
npm ci
npm run dev
```

Откройте `http://localhost:5173`. API автоматически запускается на `127.0.0.1:3002`. На странице входа есть демонстрационный вход; также можно зарегистрировать отдельного учебного пользователя. Поиск фильтруется по кухне, району и цене, а после входа доступны профиль и создание, изменение и отмена бронирований.

ЛР2 запускается такими же командами из `labs/К3440/Макаров Егор/lab2`, её интерфейс доступен на `http://localhost:5172`. **ЛР2 и ЛР3 не следует запускать одновременно с настройками по умолчанию:** обе используют API-порт 3002. ДЗ5 запускается отдельно из своего каталога и не требует API.

Данные, рестораны, отзывы и бронирования демонстрационные. Приложение не оформляет реальные заказы; демо-пароли и учебный ключ JWT не предназначены для production. Не вводите настоящие персональные данные или пароли от других сервисов.

## Проверка всего комплекта приложений

Для воспроизводимого прогона добавлен [verify-course.sh](verify-course.sh). Он последовательно выполняет чистую установку зависимостей, сборку и тесты. Отдельные тестовые серверы завершаются после проверок.

```bash
# Из корня репозитория; первая установка браузера может потребовать системные библиотеки.
BROWSER_INSTALL=1 ./verify-course.sh
```

Повторный прогон с уже установленными зависимостями:

```bash
INSTALL_DEPS=0 ./verify-course.sh
```

На Linux для установки системных зависимостей Chromium при необходимости используется `npx playwright install --with-deps chromium` из каталога ЛР2, ЛР3 или ДЗ5. Возможность установки системных пакетов зависит от прав пользователя.[1]
