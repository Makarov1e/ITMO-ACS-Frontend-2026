# Домашняя работа 2 — доступность HTML

**Студент:** Макаров Егор  
**Группа:** К3440  
**Вариант:** TableTime — учебное бронирование столиков в ресторанах

## Цель и итог

Цель работы — улучшить доступность ранее реализованной ЛР2 TableTime, добавив корректную семантику, доступные имена, понятные состояния интерфейса и управляемую клавиатурную навигацию. Требование работы предписывает проверить результат Firefox DevTools и Google Lighthouse [1].

В актуальной версии добавлены и сохранены skip-link, именованные области страницы, метки полей, доступные сообщения загрузки и ошибок, нативная проверка обязательных полей и возврат фокуса после модального окна. Финальный Lighthouse Accessibility для `index.html` — **100/100**; автоматический сценарий `npm run test:a11y` прошёл **3 из 3**. Проверка проведена на локальном учебном сервере ЛР2, поэтому она не означает публикацию или обработку реальных бронирований.

## Реализация

Основная интеграция находится в [`src/app.js`](../../../../labs/К3440/Макаров%20Егор/lab2/src/app.js) и [`src/styles.css`](../../../../labs/К3440/Макаров%20Егор/lab2/src/styles.css). Статическая разметка страниц ЛР2 задаёт язык документа, skip-link и главный landmark; пример главной страницы — [`index.html`](../../../../labs/К3440/Макаров%20Егор/lab2/index.html). Полный исходный патч первоначального этапа ДЗ2 находится в [`lab2-accessibility.patch`](lab2-accessibility.patch); он создан без ANSI-управляющих символов, в точности соответствует диапазону `541c20c^..541c20c` и проверен как применимый к базовой версии `541c20c^`.

Карточки ресторанов имеют заголовок через `aria-labelledby`, альтернативный текст изображений и читаемые кнопки. Список особенностей был дополнительно исправлен после Lighthouse-аудита: вместо `aria-label` на нейтральном `div` используется семантический `ul` с элементами `li`. Это устранило нарушение `aria-prohibited-attr`. Акцент логотипа в футере получил контрастный цвет, что устранило последнее замечание `color-contrast`. Для динамических областей применены `role="status"` или `role="alert"`, `aria-live`, `aria-busy` и `aria-atomic`; декоративные символы помечены `aria-hidden`.

Формы используют видимые `label`, нативные `required`, подходящие `autocomplete` и `aria-invalid`, который добавляется только при невалидном поле. Модальная форма бронирования получает доступное имя и описание, удерживается Bootstrap как диалог и возвращает фокус вызвавшей кнопке после закрытия. Переключатель темы остаётся группой radio внутри `fieldset` с `legend` и живым статусом. Эти решения следуют рекомендациям HTML-доступности MDN [2] и правилам доступных имён WAI-ARIA [3].

## Запуск

Работа встроена в самостоятельную ЛР2. Команды запускаются из её каталога:

```bash
cd "labs/К3440/Макаров Егор/lab2"
npm ci
npm run dev
```

После запуска интерфейс доступен по адресу `http://127.0.0.1:5172/index.html`. Локальный JSON Server остаётся учебным mock API на `127.0.0.1:3002`; перед чистым прогоном данных используется `npm run reset-db`. Его контракт и ограничение области описаны в [`API.md`](../../../../labs/К3440/Макаров%20Егор/lab2/API.md).

Финальный [скриншот Firefox Accessibility Inspector](evidence/firefox-devtools/firefox-accessibility-tree-expanded.png) показывает дерево доступности главной страницы и его landmark-структуру. ## Ограничения и вывод

Проверка Firefox является ручной инспекцией дерева доступности и не заменяет тестирование с пользователями ассистивных технологий. Lighthouse и Playwright также не доказывают доступность каждого возможного сценария. При этом они подтвердили, что проверенные страницы имеют требуемые landmarks, имена интерактивных элементов, видимый маршрут пропуска, корректный модальный сценарий и отсутствие двух ранее обнаруженных автоматических нарушений.

Цель ДЗ2 достигнута в области ЛР2: доступность улучшена без изменения учебной модели API, а автоматический тест, настоящий Firefox Accessibility Inspector и повторный Lighthouse дают воспроизводимые evidence. Приложение остаётся локальной учебной демонстрацией; настоящие заявки, платежи и персональные данные не обрабатываются.
